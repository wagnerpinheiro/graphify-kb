# Task skills (generated per workspace)

Task skills turn the KB into deliverables (e.g. drafting a compliance matrix, a proposal section, a RACI analysis). They are generated only when the user approves them (in the autonomous mode of init the user delegates this approval: generate the preset templates whose material was found), at most 2–4 per workspace, so they do not compete for triggering.

## Propose
1. From discovery and the preset (`presets/<name>/task-skills/*.SKILL.md.tpl`), list candidates that match material actually present (a requirements matrix → compliance skill; a proposal template → proposal-section skill; RACI matrices → RACI skill; a transition checklist → transition skill).
2. Ask with AskUserQuestion (multiSelect), one line each: what it produces, which sources it reads, where it writes (`docs/`).

## Generate
- Path: `.claude/skills/<project>-<task>/SKILL.md` (project prefix from `kb/config.yaml` title slug or a short code the user chooses; e.g. `/acme-matrix`). The `/kb` skill keeps the plain name.
- Fill placeholders (project, prefix, sheet/column names, saved queries); keep instructions in English; first line of the body: `<!-- generated by kb-setup <KB_SETUP_VERSION> from preset <name>; sections marked <!-- manual --> are preserved on regeneration -->`.
- Each task skill must: resolve `KB` like the `/kb` skill (central engine, else `scripts/kb-engine/`, else offer to install kb-setup); use `KB ask/query/show` for facts; delegate any document reading to subagents; never write to raw/ or wiki/ (outputs go to `docs/`); cite file+page or sheet+row; surface conflicts/precedence and alerts; answer in the user's language; end with "Suggestions" when signals appear (`improvements.md`).
- Descriptions: specific, mention the deliverable and the project, avoid overlapping with `/kb` (which answers questions) and with each other.

## Regenerate
`/kb-setup skills --regenerate`: render the template again, diff against the current file, keep `<!-- manual -->…<!-- /manual -->` blocks, show the diff and ask before writing.
